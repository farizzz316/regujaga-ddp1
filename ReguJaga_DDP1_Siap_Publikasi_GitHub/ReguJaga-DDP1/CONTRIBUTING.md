# Kontribusi Kelompok ReguJaga

Proyek DDP1 mensyaratkan kontribusi aktif setiap anggota. Paket starter disusun dengan bantuan AI; anggota wajib memeriksa dan memahami kode, lalu memberi kontribusi **nyata** dari akunnya masing-masing.

1. Clone repo publik dan buat branch terpisah, contoh `fitur/validasi-input`.
2. Buka Issue (masalah nyata, uji, atau perbaikan yang disepakati), lalu kerjakan perubahan yang tercatat.
3. Jalankan `python -m unittest discover -s tests -v`.
4. Commit perubahan yang benar-benar dibuat dengan identitas Git sendiri.
5. Push branch, buat Pull Request, minta anggota lain review.
6. Merge setelah uji lulus dan review selesai.

Jangan memanipulasi tanggal, penulis, jumlah commit, atau membuat commit kosmetik untuk memberi kesan berkontribusi. Lihat [`docs/PANDUAN_GITHUB.md`](docs/PANDUAN_GITHUB.md), [`docs/RENCANA_KERJA.md`](docs/RENCANA_KERJA.md), dan [`docs/PETA_PEMAHAMAN_KODE.md`](docs/PETA_PEMAHAMAN_KODE.md).
